# 🚕 Cab Booking & Ride Analytics – SQL Project

## 📌 Project Overview

This project is a **MySQL-based Cab Booking & Ride Analytics project** designed to analyze customers, drivers, rides, revenue, operational performance, and driver performance.

The project demonstrates practical SQL concepts used in real-world data analysis, including **Joins, Subqueries, Correlated Subqueries, UNION/UNION ALL, Window Functions, CTEs, Aggregations, and CASE Statements**.

---

## 🎯 Project Objectives

The main objectives of this project are:

* Analyze cab ride transactions
* Understand driver performance
* Calculate driver earnings
* Analyze customer ride activity
* Compare ride demand across cities
* Identify high-performing drivers
* Analyze completed, pending, and cancelled rides
* Practice advanced SQL concepts using a realistic business scenario

---

## 🗂️ Database Structure

The database is named:

```sql
cab_booking
```

### Main Tables

#### 1. Drivers

Contains information about cab drivers.

| Column      | Description                   |
| ----------- | ----------------------------- |
| driver_id   | Unique driver ID              |
| name        | Driver name                   |
| city        | Driver's city                 |
| rating      | Driver rating                 |
| total_trips | Total trips completed         |
| status      | Driver active/inactive status |

#### 2. Customers

Contains customer information.

| Column      | Description        |
| ----------- | ------------------ |
| customer_id | Unique customer ID |
| name        | Customer name      |
| city        | Customer's city    |

#### 3. Rides

Contains ride transaction details.

| Column          | Description        |
| --------------- | ------------------ |
| ride_id         | Unique ride ID     |
| customer_id     | Customer reference |
| driver_id       | Driver reference   |
| pickup_location | Pickup location    |
| drop_location   | Drop location      |
| ride_date       | Ride date and time |
| fare            | Ride fare          |
| distance_km     | Distance travelled |
| duration_min    | Ride duration      |
| status          | Ride status        |

The `rides` table connects customers and drivers using foreign keys.

## 🧠 Advanced SQL Analysis

### Driver Ranking

Used `RANK()` to rank drivers based on total earnings.

```sql
RANK() OVER (
    ORDER BY SUM(fare) DESC
)
```

### Running Total

Calculated the cumulative fare generated by each driver over time using:

```sql
SUM(fare) OVER (
    PARTITION BY driver_id
    ORDER BY ride_date
)
```

### Latest Customer Ride

Used `ROW_NUMBER()` to identify the most recent ride for every customer.

### Driver Earnings CTE

Created a CTE to calculate:

* Total driver earnings
* Total completed rides

and then joined it with the driver table for detailed analysis.
